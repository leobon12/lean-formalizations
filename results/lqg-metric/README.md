# Existence and uniqueness of the Liouville quantum gravity metric

Lean formalization of **Theorems 1.1 and 1.2** of Ewain Gwynne and Jason Miller,
[*Existence and uniqueness of the Liouville quantum gravity metric for γ ∈ (0,2)*,
arXiv:1905.00383v3](https://arxiv.org/abs/1905.00383v3), *Inventiones Mathematicae* 223 (2021).

For every **0 < γ < 2**, the formalization proves that suitably normalized Liouville first passage
percolation (LFPP) converges in probability to a metric determined by the Gaussian free field,
and that the γ-LQG metric is unique up to a deterministic positive constant. The release also
includes the existence of a normalized whole-plane GFF, so the fields in these statements exist.

## Results and proof entrypoints

All declarations below are in the `LQGMetric` namespace. The two headline proofs have exactly
the linked statements as their types, without additional unproved literature hypotheses.

| Result | Statement | Proof |
| --- | --- | --- |
| **Theorem 1.1 — LFPP convergence.** For a whole-plane GFF plus a bounded continuous function, the normalized LFPP metrics converge in probability, locally uniformly on ℂ × ℂ, to a random metric almost surely determined by the field. | [`Theorem11`](../../LQGMetric/Statement/Thm11.lean) | [`theorem11_proved`](../../LQGMetric/Assembly/MainFinal.lean) |
| **Theorem 1.2 — existence and uniqueness.** The limit is a strong γ-LQG metric satisfying Axioms I–IV. Two companions, [`theorem11_proved_measurable` and `theorem12_existence_measurable`](../../LQGMetric/Assembly/MainFinal.lean),
also state explicitly that the events used in convergence in probability are measurable up to null sets.

## Correspondence with the paper

**Normalization.** The constant 𝔞_ε is the **lower median of the whole-plane LFPP distance between
the left and right sides of the unit square**, under the normalized whole-plane GFF law
(`h₁(0) = 0`). Paths may leave the square. This follows the reading of Gwynne–Miller recorded
in the project; DDDF and DFGPS use an internal square-crossing median. The proof includes the
comparison needed to pass between those normalizations. See the [normalization definition](../../LQGMetric/Statement/LFPP.lean)
and the [differences note](differences.pdf).

**Fields and parameters.** Fields are distributions with the σ-algebra generated by test-function
pairings. The whole-plane GFF is specified modulo an additive constant. A continuous perturbation
is a measurable random continuous function on the same probability space as the field.
The parameter is ξ = γ/d_γ, with d_γ = 2/χ and χ the Liouville graph-distance exponent;
the supporting existence and uniqueness results are proved in the dependency chain.

**Convergence and uniqueness.** The limit ε → 0⁺ runs through all positive real scales.
Convergence is in probability for the local uniform topology. “Determined by h” means equal
almost surely to a measurable function of h. The uniqueness constant is chosen before the
probability space and field; equality holds simultaneously at all pairs of points outside
one null set for each field. Probability spaces range over Lean's `Type` universe.

**Scope of the supporting papers.** The release contains the local proof dependencies needed
for the two main theorems, including results from the confluence, fractal-dimension,
Liouville graph-distance, LFPP tightness, weak-metric and local-metric papers. Some intermediate
results are proved in corrected or specialized forms. This does not claim a literal formalization
of every statement in those papers, or of every corollary in Gwynne–Miller.

## Verification and reproduction

The project uses **Lean `v4.34.0-rc2`** and **Mathlib `a4c8ef0a69f52ec80525d5086bb3542f4660faaf`**.
All 3,400 local modules in the new theorem's import closure are included, with their original
bytes and source hashes. Of these, 951 were already present in the Quantum Zipper release.
No access to the private development repository is needed.

After installing [elan](https://github.com/leanprover/elan), Git and Python 3:

```sh
git clone https://github.com/leobon12/lean-formalizations.git
cd lean-formalizations
lake exe cache get
python3 scripts/verify.py
```

This checks the source manifest, rebuilds the public proof libraries, and runs the combined
[certificate](../../Certificate.lean). The certificate checks the headline types and traverses
the declarations' dependencies, allowing only `propext`, `Classical.choice` and `Quot.sound`.
The full build is substantial and can take several hours.

For just the LQG metric proof and a full kernel replay:

```sh
lake build LQGMetric.Assembly.MainFinal
lake env leanchecker --fresh LQGMetric.Assembly.MainFinal
```

The exported source scan and freshly compiled combined certificate **passed**, using previously
built modules after checking source equality. The certificate checked 84,734 project declarations
and found only the three standard axioms. See the [machine-readable result](verification.json).

The [verification record](../../VERIFICATION.md#lqg-metric-release) distinguishes the upstream
build and kernel-replay reports from checks of this public export. The
[public workflow](https://github.com/leobon12/lean-formalizations/actions/workflows/verify.yml)
records the independent rebuild for each published commit. Kernel checking establishes the
Lean proofs; correspondence with the papers is a separate question addressed by the conventions
and notes above.
