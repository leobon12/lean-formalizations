# An invariance principle for ergodic scale-free random environments

Lean formalization of **Theorem 1.16 in an interpolated-path formulation** from Ewain Gwynne, Jason Miller, and Scott Sheffield, [*An invariance principle for ergodic scale-free random environments*, arXiv:1807.07515v3](https://arxiv.org/abs/1807.07515v3).

The result gives a quenched invariance principle for random walk on planar cell configurations, recurrence, and a discrete harmonic coordinate with a uniformly sublinear corrector. The Brownian covariance is deterministic and positive definite.

The statement uses unlabelled cell configurations with the Borel structure of the topology generated by balls for the explicit GMS `dCC` formula, translation invariance modulo scaling in its mass-transport form, ergodicity, both finite-moment conditions, and connectedness along lines. The walk has deterministic holding times `Area(H) / π(H)` and allows any choice of a representative point in each cell.

The proof derives this result from the accompanying reflected-walk invariance principle. All source modules required for that derivation are included in the release.

## Correspondence with the paper

Three choices determine the precise scope:

1. **Mass transport.** Translation invariance modulo scaling is assumed in Definition 1.2(4)'s mass-transport form. The equivalence with the other forms in Appendix B is not formalized here.
2. **Interpolation.** The Lean theorem proves weak convergence of the linearly interpolated walks in `C([0,∞), ℝ²)` with uniform convergence on compact sets. GMS state convergence for step paths. The transfer from the interpolated formulation to that literal step-path formulation is not formalized here.
3. **Centroid.** The initial embedding `φ₀(H)` is the normalized centroid `Area(H)⁻¹ ∫_H z dz`, consistent with the paper's proof and face version.

The almost-sure event in the Lean statement works simultaneously for every starting cell, representative-point choice, and walk realization covered by the statement. A dedicated Lean witness satisfying all hypotheses on GMS's own configuration space is not included; the supporting reflected framework has separate non-vacuity results.

The formal statement fixes that ball-generated topology; this release does not separately certify all metric properties of the `dCC` formula.

This release certifies only the linked formal statement. It does not claim the full GMS paper or the unformalized equivalences above.
